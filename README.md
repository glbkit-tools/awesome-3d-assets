> A curated collection of free and useful 3D models, PBR textures, materials, HDRIs, environments, and other resources for 3D artists, designers, game developers, and Web 3D developers.

Finding good 3D assets can be surprisingly difficult.

Models are spread across different libraries, licenses vary between resources, and assets are often provided in formats that are not ideal for modern Web 3D workflows.

This repository brings useful resources together in one place, with a focus on:

* 3D models
* Free and CC0 assets
* PBR textures
* Materials
* HDRIs
* Environments
* GLB and glTF assets
* Three.js resources
* React Three Fiber resources
* WebGPU assets
* 3D asset optimization
* Compression and conversion tools
* Asset validation
* Developer-friendly 3D libraries

The goal is simple:

**Help developers and artists find useful 3D assets faster and understand the licensing and format requirements before using them.**

# 3D Models

Collections and resources for finding downloadable 3D models.

## Free 3D Models

* **[Poly Haven](https://polyhaven.com/)** — High-quality 3D models, HDRIs, and textures. Assets are released under CC0.
* **[Kenney](https://kenney.nl/assets)** — Large collection of game-ready assets, including many low-poly 3D assets.
* **[Khronos glTF Sample Assets](https://github.khronos.org/glTF-Assets/)** — Curated glTF models for testing, demonstrations, development, and learning.
* **[Sketchfab](https://sketchfab.com/)** — Large 3D model platform with downloadable models; check the individual asset license before use.
* **[Smithsonian 3D](https://3d.si.edu/)** — Digitized cultural heritage and scientific objects.
* **[NASA 3D Resources](https://science.nasa.gov/3d-resources/)** — 3D models and resources related to NASA missions and space science.

> **License note:** "Free download" does not automatically mean unrestricted use. Always check the license of the individual asset.

## CC0 3D Models

Resources that provide public-domain or CC0 assets.

* **[Poly Haven](https://polyhaven.com/)** — CC0 3D models, HDRIs, and textures.
* **[Kenney Assets](https://kenney.nl/assets)** — Many asset collections are available under CC0.
* **[Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)** — Includes numerous CC0 sample assets alongside assets using other licenses.
* **[OpenGameArt](https://opengameart.org/)** — Community-driven collection with multiple licensing options; verify each asset individually.

### CC0 Reminder

CC0 means the creator has dedicated the work to the public domain to the extent permitted by law.

However, **not every asset on a free-asset website is necessarily CC0**.

Always verify the license attached to the specific asset.

# 3D Asset Tools

Tools for preparing, optimizing, converting, validating, and inspecting 3D assets.

## Optimization

* **[glTF Transform](https://gltf-transform.dev/)** — JavaScript/TypeScript toolkit for processing and optimizing glTF assets.
* **[meshoptimizer](https://github.com/zeux/meshoptimizer)** — Mesh optimization algorithms and `gltfpack` for reducing mesh complexity and improving rendering efficiency.
* **[gltf-pipeline](https://github.com/CesiumGS/gltf-pipeline)** — Command-line and Node.js tools for optimizing and converting glTF assets.
* **[gltfpack](https://meshoptimizer.org/)** — Command-line glTF optimizer built around meshoptimizer.
* **[Draco](https://google.github.io/draco/)** — Geometry compression library.

---

## Compression

* **[Draco](https://google.github.io/draco/)** — Compresses 3D geometric data.
* **[meshoptimizer](https://github.com/zeux/meshoptimizer)** — Mesh compression and optimization.
* **[KTX-Software](https://github.com/KhronosGroup/KTX-Software)** — Tools and libraries for KTX/KTX2 texture processing.
* **[Basis Universal](https://github.com/BinomialLLC/basis_universal)** — Universal texture compression system designed for efficient GPU texture delivery.

For Web 3D, compression should be evaluated together with download size, decoding time, GPU upload cost, and runtime performance.

* **[Khronos glTF Blender I/O](https://github.com/KhronosGroup/glTF-Blender-IO)** — Official Khronos glTF exporter/importer for Blender.
* **[Assimp](https://github.com/assimp/assimp)** — Open Asset Import Library supporting many 3D formats.

## Validation

# Web 3D Assets

Resources specifically useful for assets that will be displayed in browsers.

## GLB / glTF

**glTF** is an open standard designed for efficient transmission and loading of 3D scenes and models.

**GLB** is the binary form of glTF and is particularly convenient for Web 3D because geometry, materials, and textures can be packaged into a single file.

Resources:

* **[Khronos glTF Specification](https://registry.khronos.org/glTF/)** — Official glTF specification and registry.
* **[Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)** — Curated glTF sample models.
* **[glTF Asset Generator](https://github.com/CesiumGS/gltf-asset-generator)** — Tools for generating glTF test assets.
* **[glTF-Blender-IO](https://github.com/KhronosGroup/glTF-Blender-IO)** — glTF import/export support for Blender.
* **[glTF Transform](https://gltf-transform.dev/)** — Processing and optimization toolkit.
* **[glTF Validator](https://github.com/CesiumGS/glTF-Validator)** — Validate glTF assets.

# Choosing 3D Assets

Before downloading or integrating an asset, consider:

### 1. License

Check whether the asset allows:

* Commercial use
* Modification
* Redistribution
* Attribution requirements
* Derivative works
* SaaS or web usage
* Marketplace distribution

### 2. Format

For Web 3D, consider:

* GLB
* glTF
* USD / USDZ where appropriate
* OBJ
* FBX
* STL
* PLY

For browser-based rendering, GLB/glTF is often a particularly practical delivery format.

### 3. Geometry

Check:

* Polygon count
* Vertex count
* Mesh count
* Draw calls
* LOD availability
* Animation complexity

### 4. Textures

Check:

* Resolution
* Number of textures
* Texture dimensions
* Compression
* PBR maps
* GPU memory requirements

### 5. Runtime Performance

A small download does not always mean a cheap asset.

Consider:

* Download size
* Decode time
* CPU usage
* GPU memory
* Texture upload time
* Rendering cost
* Mobile performance

# Licensing

Licensing is one of the most important parts of using third-party 3D assets.

A resource being described as "free" does **not** automatically mean it is:

* Public domain
* CC0
* Commercially usable
* Redistributable
* Modifiable

Always verify the license of the individual asset before using it in a project.

Common licenses include:

| License    | Typical consideration                                  |
| ---------- | ------------------------------------------------------ |
| CC0        | Public-domain dedication; generally very permissive    |
| CC BY      | Attribution required                                   |
| CC BY-SA   | Attribution + same-license requirement for adaptations |
| CC BY-NC   | Non-commercial restriction                             |
| MIT        | Permissive software license                            |
| Apache-2.0 | Permissive software license with additional terms      |
| GPL        | Strong copyleft requirements                           |

**Important:** This table is only a general overview, not legal advice.

When adding an asset to this repository, link directly to the source and make the license clear whenever possible.

# Recommended Web 3D Formats

## GLB

Best suited for:

* Web 3D
* Product viewers
* Interactive websites
* Three.js
* React Three Fiber
* Browser-based asset delivery

Advantages:

* Single binary file
* Easy distribution
* glTF ecosystem support
* Efficient browser loading
* Supports PBR materials
* Supports animations and extensions

## glTF

Useful when:

* Separate files are preferred
* Developers need to inspect individual resources
* Assets are being processed in a pipeline
* External textures are useful

## OBJ

Useful for:

* Simple geometry
* Legacy workflows
* Interchange

However, OBJ generally does not provide the same modern PBR-oriented feature set as glTF.

## FBX

Common in:

* Game development
* Animation pipelines
* DCC workflows

For Web 3D delivery, conversion to glTF/GLB is often useful.

## USD / USDZ

Useful for:

* Advanced 3D pipelines
* Apple ecosystem workflows
* AR
* Scene interchange

# 3D Asset Optimization Checklist

Before shipping a 3D asset to the Web:

```text
[ ] Verify the asset license

[ ] Remove unused meshes

[ ] Remove unused materials

[ ] Remove unused textures

[ ] Remove unnecessary animations

[ ] Reduce polygon count where appropriate

[ ] Optimize vertex/index data

[ ] Use LOD for complex assets

[ ] Compress geometry when appropriate

[ ] Compress textures

[ ] Consider KTX2 / Basis Universal

[ ] Convert to GLB/glTF where appropriate

[ ] Validate the final asset

[ ] Test on desktop

[ ] Test on mobile

[ ] Check GPU memory usage

[ ] Check loading time

[ ] Check rendering performance
```

The goal is not simply to make the file smaller.

The goal is to make the complete 3D experience **fast, visually accurate, and efficient to render**.

# Recommended Web 3D Workflow

A practical asset pipeline can look like this:

```text
Source Asset
     │
     ▼
Clean / Edit
     │
     ▼
Optimize Geometry
     │
     ▼
Optimize Textures
     │
     ▼
Compress
     │
     ▼
Convert to GLB / glTF
     │
     ▼
Validate
     │
     ▼
Test in Browser
     │
     ▼
Production
```

For large asset libraries, automate as many of these steps as possible.
